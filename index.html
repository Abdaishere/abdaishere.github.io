Case 01 · 2023

E‑Jam A test bench for network switches, spread across many machines.

My part
The Admin Client: Center Point (Rust), the Flutter client, and the Kafka layer between them
When
Jan – Aug 2023
Context
Graduation project, five developers
Licence
MIT, public on GitHub

The problem

A switch is the box every packet in an office passes through, and a new one has to prove it can carry full traffic without dropping or delaying anything. The proof is a standard set of measurements at several frame sizes, each repeated many times. Run by hand, one full pass cost an engineer more than two hours, and the hand was the slow part.

What we built

E‑Jam spreads the work across as many machines as you give it. On each one, C++ generators fire traffic at the switch and verifiers check what comes back out, every process in its own container. Their statistics stream home over Apache Kafka, typed against a schema registry, and the client charts them while the test is still running.

My part

The repository calls it the Admin Client, and it is one path: something happens on a node and it has to reach a chart. I worked on all three pieces of it. Center Point, a Rust service on Actix Web, whose REST API drives every stream, device and process through explicit state machines. The Kafka layer that carries every node's statistics home, Avro-typed against a schema registry. And the Flutter client that configures a run and draws the results live.

Case 02 · 2026

PolyBall A rhythm game I designed, coded and shipped alone.

My part
All of it: design, code, audio, release
Version
0.9.9 · downloads for desktop and Android
Status
Google Play closed testing
Runs on
Android · web · desktop

The problem

A rhythm game lives or dies on whether the tap lands on the beat, on a cheap Android phone as surely as on a desktop, in fifteen languages. With one person on the team, nothing can depend on remembering a step.

What I built

An audio engine that performs every note as you play it: sixteen additive voices, colour mapped to chord degree, bass and arpeggio and lead laid down on a swung grid. No music files ship. Around it, continuous integration across six build targets, driven by bots that play twenty-four runs a pass and miss on purpose, so the economy numbers come out looking like a real player's. Opt-in telemetry re-derived the difficulty curve from real thumbs instead of my guesses. Fifteen locales, with Arabic laid out right to left and checked by tests rather than by eye.
