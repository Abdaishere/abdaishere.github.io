Case 01

E-Jam — a distributed test bench for network switches

My part
Center Point, the Rust control plane, and the Flutter admin client
Context
Siemens EDA graduation project, remote from Cairo
When
Jan – Aug 2023
Team
Team of five · open source, MIT

Problem

One test cycle on a network switch took more than two hours, and many of the test cases were run by hand.

What we built

E-Jam spreads the load across many machines. On every node, C++ packet generators fire traffic at the switch and verifiers check what comes out, each in Docker. Apache Kafka streams their statistics back.

My part

Center Point, a Rust service on Actix Web. Its REST API drives every stream, device and process through explicit state machines, and it publishes to Kafka against a schema registry.

The Flutter admin client configures tests and charts the results live.

Outcome

  • ~10 minper test cycle, down from 2 h+
  • 5+ casesmanual tests now automated end to end, with pass/fail
  • 255 commitstop contributor to the repository

  • Actix Web
  • C++
  • Apache Kafka
  • Schema registry
  • Docker
  • Flutter

Case 02

PolyBall — a rhythm game I designed, coded and shipped alone

My part
All of it: design, code, audio, release
Version
v0.9.2
Status
Google Play closed testing
Runs on
Android · web · desktop

Problem

A rhythm game has to land every tap on the beat on Android, web and desktop, in 15 languages. With a team of one, the release process can't depend on anyone remembering the steps.

What I built

  1. An audio engine that synthesises every note at runtime: 16 additive voices, colour mapped to chord degree, no music files shipped.
  2. CI across six targets, driven by bots that play 24 runs per pass with deliberate mistakes.
  3. Opt-in telemetry, then a difficulty curve re-derived from real beta tap rates.
  4. 15 locales, with Arabic right-to-left layout covered by automated tests.
  5. Web audio fixed, iOS included, and a live leaderboard on the game page.

Outcome

  • 177 countriesin Google Play closed testing, and playable in the browser
  • −32 MBof dead payload cut from every export
  • 40 → 1.5 MBof fonts in every export
  • Godot 4
  • GDScript
  • GitHub Actions
  • Supabase
