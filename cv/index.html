The current job and the two projects first, then the internship and the degree. Nothing here is new after you download it.

  1. Apr 2025 to nowOdoo · Software Engineer, Dubai. Designed and built the first version of a stock aging layer: aging data is stored per stock move and updated on every move, with a function that rebuilds everything, so a report that walked the whole stock list now renders in under a second. Built the billing system for a third-party logistics (3PL) client: postpaid, with storage and every handling service calculated at release, and prepaid, for rented floor area. I turn what each client's business needs into a data model and a delivery plan, then build it, mainly in stock and accounting: business logic, integrations and performance fixes on 100+ enterprise client projects across the Gulf. Now building an integration with two enterprise-scale external systems, about 150 hours of work, and a multi-step approval system where requests go back and forth. Separately, I worked on payment-gateway integrations (Paymob and Wayl). I review partner developers' code against platform standards, have coached two partners and am involved in certifying partners to work with Odoo. Star of the Month, July 2026.
  2. 2026PolyBall · mobile rhythm game, built and shipped solo. Designed, built and released alone: live on Google Play in 178 countries after 19 tagged releases, 23 September to 13 November 2026. Release checks run across six build targets, with bots that play 24 runs per pass. 15 locales, with Arabic right-to-left layout covered by automated tests. A leaderboard backend with a monthly cup and server-side anti-cheat (score ceilings, run-code checks, name filter, block and report) on 11 SQL migrations with automated tests. An audio engine with 16 synthesised instruments, up to 12 notes at once, that plays every note at runtime, so the game ships no music files. Tools: Godot 4, GDScript, Supabase (PostgreSQL), GitHub Actions, Playwright. abdaishere.com/polyball.
  3. Jan to Aug 2023E‑Jam · graduation project sponsored by Siemens EDA, Cairo University. A distributed test bench that runs RFC 2544 and RFC 2889 benchmarks on network switches, built by a team of five mentored by Siemens EDA engineers. Top contributor with 256 commits. I built the control plane, a REST API that drives every stream, device and process through explicit state machines, and the admin client that configures tests and charts results live. Tools: Rust (Actix Web), Apache Kafka with Avro schemas, Flutter, Docker. The case study · open source, MIT: github.com/Abdaishere/E-Jam.
